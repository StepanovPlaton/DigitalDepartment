### **Задание №2:** 
Напишите функцию на языке программирования JavaScript, которая проверяет корректность номера кредитной карты по алгоритму Луна:
1) На вход подаётся строка с номером карты в формате четырёх групп по четыре цифры, разделённых пробелами, например: "1234 5678
9012 3456"
2) Гарантируется, что формат всегда верный
3) Преобразуйте строку, удалив пробелы, чтобы получить сплошную последовательность цифр
4) Начиная с самой правой цифры (контрольной) и двигаясь влево, удваивайте каждую вторую цифру
5) Если удвоенное значение больше 9, приведите его к однозначному путём вычитания из него 9. Пример: (16 - 9 = 7)
6) Просуммируйте все получившиеся цифры (как удвоенные, так и нет)
7) Если итоговая сумма делится на 10 без остатка, номер считается действительным, в противном случае – недействительным
8) Функция должна вернуть true если номер карты валиден, иначе же false.
> Примеры:
> - "5457 6238 9823 4311" -> true
> - "5457 6238 9323 4311" -> false

Посмотреть код выполненного задания можно в [соответствующем файле](./Task%202/index.js)

### **Задание №3:** 
Реализуйте Vue компонент, который:
1) имеет реактивную переменную value, в которую по умолчанию записано число 1000
2) рисует кнопку button, внутри которой выводится текущее значение value
3) при клике на кнопку значение value уменьшается вдвое
4) под кнопкой выводится список предыдущих значений value (массив history), который накапливает всё, что было до нажатия
5) если value меньше 1 – вместо кнопки выводится сообщение «Готово»
